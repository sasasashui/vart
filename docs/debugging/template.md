# Bug summary

## Context

Record the relevant commit, host kernel, guest artifact, and configuration.

## Symptoms

Describe observable failures and important logs without pasting excessive raw
output.

## Reproduction

Provide the smallest deterministic reproducer and the expected result.

## Investigation

Summarize useful hypotheses, experiments, and evidence. Include misleading
clues only when they teach a reusable lesson.

## Root cause

Explain the violated invariant or incorrect assumption.

## Fix

Describe the correction and why it is sufficient.

## Regression coverage

Name the test that fails before the fix and passes afterward.
