# QEMU investigations

This directory records QEMU bugs and performance work discovered while using
QEMU as VART's reference implementation and Linux test environment.

Keep one document per independently reviewable fix.  Record the observed
behavior, reproducer, root cause, each design revision, validation results,
and improvements deliberately left for later patches.  Distinguish measured
results from hypotheses, and do not describe an experimental patch as ready
for submission until its concurrency and lifetime rules have been audited.
