# NS16550A UART

VART models the UART used by QEMU's RISC-V `virt` machine: an `ns16550a` at
`0x10000000`, with a `0x100` MMIO window, register shift zero, little-endian
single-byte accesses, and APLIC interrupt source 10.

The model implements the eight standard registers, DLAB multiplexing, divisor
latches, writable masks, reset state, and synchronous transmit output. THRE and
TEMT therefore remain set.

Receive input is supplied through `vart_uart16550_receive()`. The UART has a
one-byte receive buffer, exposes LSR.DR, reports receive-data-available in IIR
when IER bit 0 is enabled, and drives its attached `VartIrq` as a level. Reading
RBR consumes the byte and lowers the interrupt. A second byte is rejected with
`-EAGAIN` until the current byte is consumed. FIFO depth, modem behavior, and
baud timing remain deferred.

The KVM integration guest polls LSR.THRE before every byte written to THR. The
host captures and compares `Hello from VART UART\n`, while the VART test device
provides a deterministic PASS/FAIL termination channel.

The AIA integration guest enables UART receive interrupts, receives a host
injected byte through APLIC source 10 and the IMSIC, reads RBR in its trap
handler, and verifies that the device lowers the wired interrupt.
