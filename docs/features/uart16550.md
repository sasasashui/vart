# NS16550A UART

VART models the UART used by QEMU's RISC-V `virt` machine: an `ns16550a` at
`0x10000000`, with a `0x100` MMIO window, register shift zero, little-endian
single-byte accesses, and future interrupt source 10.

The initial polling model implements the eight standard registers, DLAB
multiplexing, divisor latches, writable masks, reset state, and transmit output.
LSR always reports THRE and TEMT because output completes synchronously.
Receive data, FIFO contents, interrupts, modem behavior, and baud timing are
deferred without changing the guest-visible register layout.

The virt DTB places the UART below the identity-mapped `/soc` simple bus with
QEMU-compatible `ns16550a`, register-range, and 3.6864 MHz clock properties.
`/chosen/stdout-path` and `/aliases/serial0` select it as the boot console.
Interrupt properties are added with the AIA phandle topology in Stage 6.5.

The KVM integration guest polls LSR.THRE before every byte written to THR. The
host captures and compares `Hello from VART UART\n`, while the VART test device
provides a deterministic PASS/FAIL termination channel.
